# quant-research — 量化研究协作仓

本仓是**纯研究环境**，与生产系统物理隔离。所有工作以任务包（tasks/）形式下发和回收。


## 工作流

1. 领取任务包（tasks/TASK-xxx.md），先读"接口契约"和"验收标准"
2. 写一页纸预注册方案（假设 / 检验门槛 / 证伪条件），拍板后才跑实验
3. 代码 + pytest 测试 + 研究报告（markdown）提交 PR


## 目录

- `framework/` — 评估框架（接口定义，任务内实现）
- `examples/` — 参考示例（quickstart.py: 数据→因子→IC 最小闭环）
- `tasks/` — 任务包（工单）
- `data/` — 研究数据包（脱敏面板+事件清单，随 private 仓分发，禁止外传）
