# quant-research — 量化研究协作仓

本仓是**纯研究环境**，与生产系统物理隔离。所有工作以任务包（tasks/）形式下发和回收。

## 红线（违反即终止协作）

- ❌ 禁止提交任何数据文件（data/ 下内容仅限本地使用，一律不入库）
- ❌ 禁止提交任何凭证（.env、*.pem、token、API key）
- ❌ 禁止打听/讨论生产系统的部署、接口、页面、用户数据
- ❌ 研究成果（代码、报告、因子帧）归项目方所有，不得外传、不得用于个人实盘
- ✅ 只做 tasks/ 下已下发的任务；新想法先写一页纸方案，拍板后再动手

## 工作流

1. 领取任务包（tasks/TASK-xxx.md），先读"接口契约"和"验收标准"
2. 写一页纸预注册方案（假设 / 检验门槛 / 证伪条件），拍板后才跑实验
3. 代码 + pytest 测试 + 研究报告（markdown）提交 PR
4. 验收标准全绿才合并；不达标按报告意见返工

## 目录

- `framework/` — 评估框架（接口定义，任务内实现）
- `tasks/` — 任务包（工单）
- `data/` — 数据包本地存放点（内容不入库，单独分发）
